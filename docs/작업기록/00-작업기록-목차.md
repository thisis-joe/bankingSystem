## 4. 설명 문서와 작업기록의 차이

설명 문서는 개념을 이해하기 쉽게 정리한 학습용 문서다.
작업기록은 실제로 무엇을 왜 어떻게 어디에 반영했는지 남기는 변경 이력 문서다.

즉:

- 설명 문서: 이해용
- 작업기록: 추적용
