# 작업 기록

## 1. 작업명

- SDUI 실행 및 확인 방법 참고 문서 추가

## 2. 이번 작업에서 한 일

- 프로젝트 실행 명령, 접속 주소, H2 콘솔 정보, 추천 확인 순서를 정리한 참고 문서를 추가했다.
- SDUI는 JSON 화면 정의를 먼저 보고 실제 화면을 보는 것이 중요하다는 점을 문서에 반영했다.
- 코드 파일을 어떤 순서로 보면 이해가 쉬운지도 함께 정리했다.
- 읽기 순서 문서에서 이 참고 문서를 가장 앞쪽 참고자료로 보이게 연결했다.

## 3. 왜 이 작업을 했는지

- 사용자가 "어떻게 보고 실행하는지" 를 바로 확인할 수 있어야 하기 때문이다.
- SDUI는 단순 실행보다 `무슨 순서로 보면 이해가 잘 되는지` 가 특히 중요하기 때문이다.
- 이후 화면을 수정하거나 follow up 할 때, 실행 경로와 확인 경로가 고정 문서로 남아 있어야 하기 때문이다.

## 4. 어떻게 작업했는지

- 별도 설명 문서가 아니라 참고용 실행 가이드 문서를 새로 만들었다.
- 실행 명령, 접속 URL, 추천 관찰 순서, 개발자도구에서 볼 포인트까지 포함했다.
- 이 문서를 `00-문서-읽기-순서.md` 보다 먼저 참고할 수 있도록 앞단 참고자료로 배치했다.

## 6. 학습 포인트

- SDUI는 JSON 화면 정의를 먼저 보고 실제 화면을 보면 이해가 더 쉽다.
- 실행 문서는 기능 문서와 별도로 두면 나중에 반복 확인하기 좋다.
- 학습용 프로젝트에서는 "무엇을 만들었는가" 만큼이나 "어떻게 확인하는가" 문서가 중요하다.
